# 慧生活798 自动化积分脚本

基于慧生活798（`com.cloudora.android`）逆向协议还原的自动化任务工具。支持自动签到、激励视频与全屏广告任务执行、多账号凭证管理与原生定时挂机。

**本脚本仅供学习研究，请勿用于违规途径！**
## 快速上手

### 1. 安装环境依赖

脚本仅依赖 `requests` 库，定时调度由 Python 原生标准库驱动：

```bash
# 确认 Python 版本 >= 3.8
python --version

# 安装网络请求依赖
pip install requests
```

### 2. 账号录入与启动

在脚本所在目录下直接运行：

```bash
python auto_score.py
```

* **首次运行**：会自动引导录入账号。在控制台输入手机号后，复制输出的链接到任意浏览器查看图形验证码，回车输入图形码及收到的短信验证码完成登录。
* **多账号支持**：登录成功后会询问 `是否添加新账号？[y/N]`，输入 `y` 即可依次绑定多个账号。
* **本地凭证**：登录成功后凭证将加密保存在同目录下的 `ilife_accounts.json`，后续启动免验证直接执行。

## 常用部署方案

### Windows 快捷运行
在脚本同目录下创建 `run.bat`，写入以下内容保存后即可双击运行：
```bat
@echo off
python auto_score.py
pause
```

### Linux / VPS / NAS 后台挂机 (推荐)
通过 `nohup` 让进程在后台 24 小时保持运行，终端退出不中断：

```bash
# 后台常驻运行并将日志输出至当前目录的 ilife.log
nohup python3 -u auto_score.py > ilife.log 2>&1 &

# 实时查看挂机日志
tail -f ilife.log

# 停止后台运行
ps -ef | grep auto_score.py
kill -9 <PID>
```

## 常见问题与排查

1. **Token 失效/过期**：
   平台 Token 过期后，脚本启动时会提示凭证失效，并自动拉起交互式短信验证码登录完成重签刷新。
2. **触发 `-98 请求过于频繁`**：
   当日高频调试或在短时间内多次运行可能触犯服务端频控。脚本遇到该状态会自动终止后续无谓请求，次日服务器重置状态后即可恢复正常。
3. **调整每日执行时间**：
   可在脚本底部的启动调用中修改目标时间（24小时制）：
   ```python
   run_scheduler(target_time="08:15")
   ```
